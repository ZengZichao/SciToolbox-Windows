## 1. 界面总览

窗口分三栏，外加一条顶部工具栏。

**顶部工具栏**（从左到右）

| 元素 | 作用 |
| --- | --- |
| 侧边栏开关 | 显示 / 隐藏左侧导航栏，等同 `Ctrl` + `\` |
| 返回 | 回到上一个看过的工具，跨库跳转后特别有用 |
| 面包屑 | 显示最近三步的浏览路径 |
| 缓存 / 限流提示 | 命中本地缓存或正在排队等待接口时出现 |
| 搜索（右上） | 打开命令面板，等同 `Ctrl` + `K` |
| 列表图标（右上） | 打开键盘快捷键速查 |

**左栏 · 导航**：首页、按五大分类分组的 15 个数据库、收藏与历史、项目集合、设置。分类标题可以点击折叠，折叠状态会被记住。

**中栏 · 检索与结果**：标题、检索框、结果列表。

**右栏 · 详情**：选中某条结果后在这里展开；没有选中时显示引导提示。

三栏之间的分隔线都可以拖动调整宽度。

## 2. 检索一条记录

1. 左侧选一个数据库（例如 **UniProt 蛋白质**）。
2. 在检索框输入关键词或编号，回车或点右侧放大镜图标。
3. 结果逐行显示：主标题、副标题、编号徽标与摘要信息。
4. 点击任意一行，右栏加载该条目的完整详情。
5. 结果较多时底部出现"加载更多"，分页追加，不会重复请求已有内容。

**行内操作**

- 每行右侧的星形图标可直接收藏 / 取消收藏，不必先打开详情。
- 按住 `Ctrl` 点击多行，可一次选中多条做批量处理。
- 用 `↑` `↓` 在列表里移动高亮，`Enter` 打开高亮项。

**结果内筛选**：结果出来后，上方的"本地过滤"框只在**已经加载**的结果里做文本匹配，不会重新请求接口。清空该框即恢复完整列表。

## 3. 智能识别与跨库跳转

**首页的"快速上手"输入框**是通用入口：把编号直接粘进去，点"识别并打开"，应用会判断它属于哪个数据库并跳转。

可识别的常见形式：

| 输入 | 去向 |
| --- | --- |
| `P12345`、`Q9Y697` | UniProt |
| `1ABC`、`4HHB` | RCSB PDB |
| `TP53`、`BRCA2` | 基因符号 → NCBI Gene / Ensembl |
| `10.1000/xyz...` | DOI → Europe PMC |
| `GO:0006915` | QuickGO |
| `PF00069`、`IPR000719` | Pfam / InterPro |
| `ENSG00000141510` | Ensembl |
| `hsa04110`、`C00001` | KEGG |
| 数字 TaxID | NCBI Taxonomy |

**出现歧义时**（比如某个编号在多个库里都说得通），会弹出候选列表，列出每个候选的目标库、查询词、判断理由和置信度百分比，点选即可。

**详情页内的跨库互链**：很多字段本身就是链接，例如 UniProt 条目里的 PDB 结构编号、PDB 条目里的 UniProt 编号。点击会切换目标库并自动完成检索，顶栏"返回"可回到上一个库。

## 4. 全库搜索

首页的"全库搜索"输入一个关键词，会**并行**查询全部 15 个数据库，结果按五大分类分组展示，每个库显示命中数量和前 5 条摘要。

- 单个库失败或超时不影响其他库，失败的库会单独标注原因。
- 每个库右侧的"打开"按钮，把该关键词带到对应库里做完整检索。
- 顶部显示当前查询词，可点"重试"重新发起。

适合"只知道一个基因名 / 蛋白名 / 课题词，不确定该去哪个库"的场景。

## 5. 查看详情

选中结果后，右栏按区块展示：

- **顶部色条**：颜色代表该条目所属的分类。
- **标题区**：主标题、副标题、若干元信息胶囊。
- **操作图标**：收藏、加入集合、加入对比、在官网查看。
- **结构 / 通路预览图**（仅 PDB、AlphaFold、KEGG 等有图的条目）。
- **分组字段表**：每组有标题，字段为"键 — 值"两列；值可以点选复制，带复制图标的字段一键复制。
- **长文本区块**：摘要、注释、序列说明等整段内容。
- **动作按钮**：该条目可用的导出操作（复制 FASTA、导出 BibTeX 等）。
- **跨库互链**：相关条目列表，点击直接跳转。

详情浏览有历史栈，用 `Ctrl` + `[` / `Ctrl` + `]` 或右栏顶部的箭头按钮前后翻。

加载失败时不会静默变白，会显示具体原因和"重试"按钮。

## 6. 收藏、历史与项目集合

**收藏**：详情页或结果行的星形图标。支持给收藏加备注、按关键词过滤、导出为文本或 JSON、单条删除（删除后左下角出现"撤销"）。

**查询历史**：每次成功检索都会记下来。点"重查"直接复用该查询；单条删除可撤销；也可整体清空。

**项目集合**：把一组相关条目按课题归档。

1. 侧边栏进入"项目集合"，点"新建集合"，输入名称。
2. 在任意详情页或结果行选择"加入集合"，挑选目标集合，或当场新建。
3. 打开某个集合可查看条目列表，支持逐条加备注、移出、重命名、删除集合。
4. 集合可导出 **CSV**（便于在表格软件里继续处理）或 **JSON**（完整结构备份）。
5. "批量核对"会逐条重新拉取最新数据，用于确认编号是否仍然有效；过程中显示进度。

## 7. 批量操作与对比

**批量操作**：在结果列表点"进入多选"，或直接 `Ctrl` + 点击若干行。选中后工具条提供：

| 操作 | 结果 |
| --- | --- |
| 复制编号 | 把选中条目的 accession 按行复制到剪贴板 |
| 批量收藏 | 一次收藏全部选中项 |
| 加入集合 | 弹集合选择框，批量归档 |
| 导出表格 | 生成 CSV 文件（编号 / 标题 / 副标题 / 其他信息） |

**对比**：把条目"加入对比"（最多 4 条），右栏顶部出现对比条，点"查看对比"进入并排视图，字段按统一口径对齐，便于横向比较同名不同库的条目。

## 8. 导出与引用格式

| 内容 | 格式 | 来源 |
| --- | --- | --- |
| 蛋白 / 基因 / 序列 | FASTA | UniProt、Ensembl、AlphaFold |
| 文献条目 | BibTeX、RIS | PubMed、Europe PMC |
| 检索结果 / 集合 | CSV | 批量导出、集合导出 |
| 收藏 / 全部本地数据 | JSON | 设置页与收藏页 |

动作按钮默认复制到剪贴板，标注"导出"的会弹出保存文件对话框。BibTeX / RIS 可直接被 Zotero、EndNote、Mendeley 导入。

## 9. 各数据库能力差异

| 工具 | 检索建议 | 特色 |
| --- | --- | --- |
| UniProt 蛋白质 | accession、基因名、物种 + 关键词 | 序列 FASTA 复制、结构互链 |
| RCSB PDB 结构 | 4 位 PDB ID | 结构预览图、实验方法 / 分辨率 |
| AlphaFold 结构 | UniProt accession | 预测结构图与置信度 |
| PubMed 文献 | 支持 PubMed 检索语法 | **可按年份范围筛选**、BibTeX / RIS |
| Europe PMC 文献 | PMID、DOI、关键词 | 开放获取标记、BibTeX / RIS |
| NCBI 基因/序列 | 基因名 / GeneID | 跨库互链密集 |
| NCBI 分类检索 | 学名或 TaxID | 分类谱系链 |
| Ensembl 基因 | 基因名 / ENSG | 序列 FASTA、坐标信息 |
| KEGG 在线检索 | `hsa04110`、化合物号 | 通路图预览 |
| GO 术语查询 | `GO:0006915` 或术语名 | 本体层级 |
| Pfam / InterPro | `PF00069`、`IPR…` | 家族 / 结构域注释 |
| GBIF 物种 | 学名 / 俗名 | 物种分类与分布记录 |
| BacDive 菌株 | 菌株名 / 分类号 | 微生物株系信息 |
| MGnify 微生物组 | 研究编号 | 宏基因组研究 |
| GTDB 官方分类 | 分类单元名 | 打开即预载列表，无需先输入 |

## 10. 设置项说明

| 分组 | 选项 | 说明 |
| --- | --- | --- |
| 外观 | 主题 | 跟随系统 / 浅色 / 深色；跟随系统时，改 Windows 主题会即时生效 |
| 外观 | 侧边栏密度 | 紧凑 / 正常 / 宽松，调整导航行高与字号 |
| 外观 | 界面语言 | 中文 / English，切换后界面即时更新 |
| 缓存 | 启用结果缓存 | 关闭后每次都重新请求；可单独清除全部缓存 |
| 缓存 | 键盘快捷键 | 打开快捷键速查 |
| 数据管理 | 导出全部本地数据 | 收藏 + 历史 + 集合打包成 JSON |
| 数据管理 | 清除全部收藏 / 历史 | 二次确认后执行 |
| 数据管理 | 重置应用 | 清空所有本地数据（含缓存），需二次确认 |

## 12. 数据存放位置与清除

所有本地数据都在这一台机器上：

```
%LOCALAPPDATA%\SciToolbox\
├── prefs.json     # 偏好设置 + 查询历史 + 收藏 + 项目集合
├── Cache\         # 接口响应缓存
├── crash.log      # 运行异常记录（有异常时才生成）
└── binding.log    # 界面绑定诊断输出（仅 --trace 时生成）
```

- 想备份或迁移：复制 `prefs.json`，或用设置页的"导出全部本地数据"。
- 想彻底清除：设置页"重置应用"，或直接删除该目录。

应用不写入注册表，也不把任何数据发送到除目标数据库官方接口之外的地址。

## 13. 常见问题

**搜不到结果**
先确认顶部没有出现离线提示条。若某个库确实没有匹配，结果区会给出提示，并可一键"在所有数据库中搜索"。

**提示"请求过于频繁"**
这是 NCBI 等接口的频率保护。应用会自动排队并退避重试，稍候即可，无需重复点击。

**详情一片空白**
现在会显示具体错误原因和"重试"按钮。若接口本身返回为空，说明该编号在这个库里没有对应记录，试试跨库互链或换一个库。

**改了系统主题，应用没跟着变**
把设置里的主题选为"跟随系统"，应用会在运行时监听系统偏好变化。

**界面文字一半中文一半英文**
切换语言后所有文案会立即重算。若个别字段仍是另一种语言，那通常来自数据库接口本身返回的内容，不是界面文案。

**数据丢了**
检查 `%LOCALAPPDATA%\SciToolbox\prefs.json` 是否存在。若曾手动清理过该目录，数据无法恢复——建议定期用"导出全部本地数据"备份。
